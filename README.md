# 🎲 Minha Mesa de RPG

### Sua mesa de RPG, do seu jeito!

A **Minha Mesa de RPG** é uma plataforma independente em desenvolvimento, criada para proporcionar uma experiência de mesa virtual de RPG diretamente pelo navegador.

O objetivo é oferecer aos Mestres e jogadores um ambiente onde possam compartilhar mapas, movimentar personagens, explorar cenários e jogar juntos, mesmo estando em computadores diferentes.

## 🌐 Acesse a plataforma

**[🎲 Entrar na Minha Mesa de RPG](https://rpg-platform-tx9a.onrender.com/)**

## ⚔️ Funcionalidades

- 🗺️ Mapas interativos com zoom e movimentação.
- 🎭 Tokens para representar personagens e criaturas.
- 🎲 Rolagem de dados.
- 👑 Ferramentas exclusivas para o Mestre.
- 🌫️ Sistema de neblina e exploração do mapa.
- 💡 Sistema de visão dinâmica.
- 🧱 Paredes e obstáculos para controlar a visão.
- 👥 Salas multiplayer para jogar com outras pessoas.

*Algumas funcionalidades ainda estão em desenvolvimento e podem apresentar erros.*

## 🎮 Como participar dos testes?

1. Acesse a plataforma pelo link acima.
2. Para criar uma mesa, utilize a opção **Criar sala**.
3. Para participar de uma mesa existente, informe o código fornecido pelo Mestre.
4. Divirta-se e ajude a melhorar o projeto!

## 💬 Sugestões e problemas

Encontrou algum erro ou tem uma ideia para melhorar a plataforma?

Sua opinião é muito bem-vinda! Sugestões, críticas construtivas e relatos de problemas ajudam a tornar o projeto cada vez melhor.

## 🚧 Sobre o projeto

A Minha Mesa de RPG é um projeto independente, desenvolvido com HTML, CSS, JavaScript, Node.js e Socket.IO.

O objetivo é continuar evoluindo a plataforma, priorizando a experiência dos jogadores e oferecendo cada vez mais ferramentas para os Mestres.
