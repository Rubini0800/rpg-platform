RPG Platform v8 — correções de ferramentas e tokens

Mudanças desta versão:
- Menu Ferramentas com rolagem vertical para alcançar todos os controles.
- Corrigido o estado desabilitado do botão Revelar área; os controles de neblina e paredes são liberados para o Mestre conectado.
- A imagem do mapa fica abaixo da grade alinhada, enquanto tokens e neblina mantêm camadas próprias.
- Selecionar um token e usar as setas do teclado move o token; Shift + seta move aproximadamente um quadrado.
- Teclas Q/E giram o token em passos de 15 graus. Também há uma alça ↻ sobre o token selecionado para girar com o mouse.
- A rotação é enviada pelo Socket.IO e salva junto do estado do token.
- A opção de ocultar/revelar token para jogadores foi mantida.

Instalação segura:
1. Pare o servidor com Ctrl+C.
2. Faça backup do campanhas-salvas.json da pasta em uso.
3. Extraia este ZIP em uma pasta separada.
4. Copie os arquivos do projeto, mas NÃO substitua o campanhas-salvas.json que já está na sua pasta.
5. Execute npm install (se necessário) e depois node server.js.
6. Teste as ferramentas como Mestre e confirme a visão com um segundo navegador conectado como jogador.

Observação: os arquivos JS foram verificados com node --check e o ZIP foi validado. Não foi possível fazer teste visual de navegador nesta sessão.
